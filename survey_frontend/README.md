# React Schema Preview

This app includes a static, Tailwind-styled schema preview for a Survey platform.

## What’s included
- Visual cards of tables: users, surveys, questions, options, responses, answers
- Field names, types, notes
- Relationship list
- No backend calls; this is for reference only

## Run locally
- `npm start` and open http://localhost:3000

## SQL schema
See `../database/schema.sql` for the PostgreSQL DDL with UUIDs using `gen_random_uuid()` and FK constraints.
